Visit-access QR tool

Development helper for MP-97. It displays the QR returned by POST /api/appointments/{appointmentId}/start-visit, scans that code with the camera, and lets the patient approve or reject the request. The JWT and the QR token stay in this page's memory only; nothing is stored or logged.

1. Patient sign-in

Only the Patient role can scan and answer a request.

2. Display the doctor's QR

The doctor runs start-visit in Swagger, copies qrCodeDataUri, and pastes it here. The QR is valid for two minutes.
